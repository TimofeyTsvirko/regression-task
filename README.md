## Постановка задачи

Целью работы является построение модели регрессии, способной прогнозировать рыночную стоимость бриллианта на основе его физических и качественных характеристик.

В качестве целевой переменной используется признак `price`, содержащий стоимость бриллианта в долларах США.

**Названия столбцов с пояснением:**

| Столбец | Тип данных | Описание |
|----------|------------|----------|
| `carat` | `float` | Вес бриллианта в каратах. Один из наиболее важных факторов, влияющих на стоимость. |
| `cut` | `category` | Качество огранки бриллианта: `Fair`, `Good`, `Very Good`, `Premium`, `Ideal`. Чем выше качество огранки, тем лучше отражается свет и выше стоимость камня. |
| `color` | `category` | Цвет бриллианта по шкале GIA: от `D` (абсолютно бесцветный, высшее качество) до `J` (имеет заметный оттенок). |
| `clarity` | `category` | Чистота бриллианта, характеризующая количество и размер внутренних и внешних дефектов: `I1`, `SI2`, `SI1`, `VS2`, `VS1`, `VVS2`, `VVS1`, `IF`. |
| `depth` | `float` | Общая глубина бриллианта в процентах: отношение высоты камня к его среднему диаметру. |
| `table` | `float` | Ширина площадки (верхней грани) бриллианта в процентах от его среднего диаметра. |
| `price` | `int` *(целевая переменная)* | Рыночная стоимость бриллианта в долларах США. Это целевая переменная, которую необходимо предсказать. |
| `x` | `float` | Длина бриллианта (мм). |
| `y` | `float` | Ширина бриллианта (мм). |
| `z` | `float` | Высота бриллианта (мм). |
